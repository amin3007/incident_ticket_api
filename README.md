# Incident Ticket API

A REST API for managing internal IT incident tickets.

## Project Goal

This project demonstrates backend development with Spring Boot, PostgreSQL, validation, testing, Docker, OpenAPI documentation, and a CI pipeline.

## Current Status

Basic Spring Boot project setup is complete.

## Tech Stack

1. Java 21
2. Spring Boot
3. Maven
4. Spring Web
5. Spring Data JPA
6. PostgreSQL
7. Validation
8. Spring Boot Actuator

## Local Start

```bash
./mvnw spring-boot:run
